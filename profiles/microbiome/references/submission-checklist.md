# Microbiome (BMC) submission gate (S5) — HARD/SOFT

HARD:
- [ ] Manuscript type correctly selected from the 8 available: Research,
      Methodology, Brief report (Short report), Software, Review, Comment,
      Correspondence, Meeting Report. VERIFIED 2026-07-04. Review,
      Comment, and Meeting Report are typically editor-commissioned —
      unsolicited Reviews are explicitly NOT considered ("Reviews published
      in the journal are specially invited by the Editors of Microbiome").
      Do not submit an unsolicited Review.
- [ ] Abstract within limit and structure for the declared type: Research /
      Methodology / Brief report / Software <=350 words, structured
      Background/Results/Conclusions; Comment <=350 words, structured
      background/main body/short conclusion; Review <=350 words,
      unstructured; Meeting Report <=250 words, unstructured; Correspondence
      has no numeric cap found (brief summary only — see SKILL.md TO
      VERIFY). No abbreviations, no references cited in any abstract.
      VERIFIED 2026-07-04.
- [ ] Section order matches the declared type's verified structure (see
      `profile.yml` `section_headings` for the Research/IMRaD baseline and
      each type's own `counting_rule` for its actual structure — Review/
      Comment/Correspondence/Meeting Report drop Background/Methods/
      Results/Discussion for a plain "Main text"). VERIFIED 2026-07-04.
- [ ] Declarations section present with ALL of: Ethics approval and consent
      to participate; Consent for publication; Availability of data and
      materials; Competing interests; Funding; Authors' contributions;
      Acknowledgements (Authors' information is optional) — every
      subsection present even when "Not applicable." Mandatory for EVERY
      manuscript type. VERIFIED 2026-07-04.
- [ ] Data availability: all datasets the conclusions rely on are available
      to reviewers at submission and publicly available at publication. For
      sequence data: sampling/extraction/PCR-amplification negative
      controls plus positive controls (mock communities or others)
      included; metadata formatted to MIxS (GSC) standards; all original
      sequences deposited in a public repository. VERIFIED 2026-07-04
      (Research article page — apply the same standard to Methodology/
      Brief report/Software, which share the same IMRaD/Declarations
      shape).
- [ ] No TOC/graphical abstract required or expected — do NOT block on a
      missing graphic; this journal has none. VERIFIED ABSENT 2026-07-04
      (`profile.yml` `toc_graphic.required: false`).
- [ ] References: numbered consecutively in square brackets, in order of
      first citation; only published/in-press articles, registered
      clinical trials, or in-press abstracts may be cited; journal
      abbreviations follow Index Medicus/MEDLINE. All citekeys resolve
      against `assets/biomed-central.csl`. VERIFIED 2026-07-04.
- [ ] Figures: <=10 MB per file, ~300 dpi at final size, width 85 mm
      (half page) or 170 mm (full page), max height 225 mm, lines >0.25 pt;
      titles (<=15 words) and legends (<=300 words) in the manuscript text,
      not the image; figure keys baked into the graphic; multi-panel
      figures as one composite file. VERIFIED 2026-07-04.
- [ ] Tables: numbered with Arabic numerals in citation order; title
      (<=15 words) above, legend (<=300 words) below; built with Word's
      native Table object, not an image/spreadsheet; no color/shading; no
      commas in numerical values. VERIFIED 2026-07-04.
- [ ] Additional files (if any): named "Additional file 1," "Additional
      file 2," etc., each cited in the main text; <=20 MB each; multiple
      formats accepted (NOT single-merged-PDF-only). Do NOT include patient
      consent forms, language-editing certificates, or tracked-change
      manuscript versions as additional files — send those by email to the
      editorial address instead. VERIFIED 2026-07-04. SI cover sheet and
      internal-pagination-prefix requirements are UNCONFIRMED (see SKILL.md
      TO VERIFY) — do not fabricate an S1/S2 scheme for this journal
      without re-checking.
- [ ] Formatting: double-line spacing, line and page numbering, no page
      breaks; file format DOC/DOCX/RTF/TeX-LaTeX. VERIFIED 2026-07-04.
- [ ] Competing interests declared in the cover letter AND in the
      Declarations block. VERIFIED 2026-07-04.
- [ ] Cover letter confirms all authors have approved the manuscript for
      submission; a manuscript can only be submitted by one of its own
      authors, never a third party. VERIFIED 2026-07-04.
- [ ] Any LLM use in preparing the manuscript is disclosed — "Large
      Language Models (LLMs), such as ChatGPT, do not currently satisfy our
      authorship criteria." VERIFIED 2026-07-04.
- [ ] Open-access route confirmed; APC £3,590.00 GBP / $5,190.00 USD /
      €4,290.00 EUR budgeted or a waiver path identified. VERIFIED
      2026-07-04.
SOFT:
- [ ] Suggested peer reviewers drafted, with institutional email addresses
      and/or an ORCID or Scopus ID to help verify identity (the journal's
      own recommended practice for author-suggested reviewers). VERIFIED
      2026-07-04. This is the ONLY context in which the fetched guidance
      mentions ORCID at all — general author ORCID requirements are
      UNCONFIRMED (see SKILL.md TO VERIFY).
- [ ] Ethics-committee name and approval reference number ready for the
      Declarations block, if human/animal subjects are involved. VERIFIED
      2026-07-04 (BMC-wide policy).
- [ ] Preprint posting decision made — UNCONFIRMED policy either way (see
      SKILL.md TO VERIFY); do not assume preprints are barred or blessed.
