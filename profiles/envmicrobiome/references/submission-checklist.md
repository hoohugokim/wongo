# Environmental Microbiome submission gate (S5) — HARD/SOFT

Sources: see `profile.yml` `sources:` and `SKILL.md` VERIFIED section
(fetched 2026-07-04). Environmental Microbiome does not impose a stated
main-text word limit on any article type — most HARD items below are
structural/declaration requirements, not counting rules.

HARD:
- [ ] Article type declared and its own section structure followed exactly
      (Research/Methodology/Brief report/Software use Background-Methods-
      Results-Discussion-Conclusions with Declarations; Review/Perspective/
      Comment use Main text + Conclusions with Declarations but different
      abstract structure; Correspondence/Meeting report use a bare Main
      text with NO Conclusions heading). VERIFIED 2026-07-04, per-type
      breakdown in `profile.yml` `manuscript_types[].counting_rule`.
- [ ] Abstract within the type's rule: Research/Methodology/Brief report/
      Software <=350 words, STRUCTURED Background/Results/Conclusions;
      Review <=350 words, UNSTRUCTURED; Perspective/Comment <=350 words,
      structured background/main-body/conclusion prose; Correspondence/
      Meeting report unstructured, no numeric cap. No references cited in
      any abstract; minimize abbreviations. VERIFIED 2026-07-04.
- [ ] If article type is Review: confirm this is a COMMISSIONED review, not
      an unsolicited submission — "Environmental Microbiome no longer
      considers unsolicited reviews" (verbatim). VERIFIED 2026-07-04. Do
      not proceed with an unsolicited Review without editor confirmation.
- [ ] 'Declarations' heading present with ALL eight subheadings in order:
      Ethics approval and consent to participate / Consent for publication
      / Availability of data and materials / Competing interests / Funding
      / Authors' contributions / Acknowledgements / Authors' information
      (optional, may be omitted entirely rather than "Not applicable"-ed).
      Every other subheading MUST appear even if the answer is "Not
      applicable" — do not silently drop a subheading with nothing to say.
      VERIFIED 2026-07-04.
- [ ] Availability of data and materials statement uses one of BMC's
      template sentence forms and, if applicable, cites deposited datasets
      in the reference list with a DOI/accession number. VERIFIED
      2026-07-04.
- [ ] For Research/Methodology/Brief report specifically: mandatory
      sampling, extraction, and PCR-amplification NEGATIVE controls PLUS
      POSITIVE (mock-community) controls, sequenced and deposited publicly
      alongside sample data; metadata formatted to the MixS standard.
      VERIFIED 2026-07-04 — this is a journal-specific methodological gate,
      not generic BMC boilerplate; check it before assuming any BMC
      microbiome-adjacent profile's checklist transfers directly.
- [ ] Microbial taxon names italicized (kingdom through subspecies); strain
      designations/numbers NOT italicized. "16S rRNA gene" terminology used
      throughout (never "16S"/"16S rDNA"/"16S rDNA gene"/"16S gene").
      VERIFIED 2026-07-04.
- [ ] Any co-association network analysis uses compositionally-aware
      methods (not raw Pearson/Spearman correlation alone). VERIFIED
      2026-07-04 (Research/Methodology/Brief report/Software Criteria
      sections).
- [ ] No TOC/graphical abstract required or expected — do NOT block on a
      missing graphic; this journal has no such concept anywhere in its
      fetched guidance. VERIFIED ABSENT 2026-07-04 (`profile.yml`
      `toc_graphic.required: false`).
- [ ] References: BioMed Central / Vancouver-family numbered style, square
      brackets, order of first appearance; only footnotes permitted beyond
      the numbered list; journal abbreviations per Index Medicus/MEDLINE.
      All citekeys resolve against `assets/biomed-central.csl`. VERIFIED
      2026-07-04.
- [ ] Figures: uploaded as separate files (not embedded in the manuscript
      document), numbered/ordered by first mention, multi-panel figures as
      ONE composite file, titles <=15 words and legends <=300 words placed
      in the MAIN TEXT (not the graphic), figure keys baked into the
      graphic, <=10 MB per file. VERIFIED 2026-07-04.
- [ ] Tables: Arabic numerals, native "Table object" formatting (never an
      embedded image/spreadsheet), no color/shading, titles <=15 words
      above / legends <=300 words below, no commas in numeric values.
      VERIFIED 2026-07-04.
- [ ] Additional files (if present): each a SEPARATE file (not one merged
      SI PDF), named "Additional file 1", "Additional file 2"... , <=20 MB
      each, cited explicitly by name in the main text, with a manifest
      (file name/format/title/description) listed in its own section of
      the MAIN manuscript text — not a standalone SI cover sheet and not an
      internal SI table of contents (neither exists for this journal).
      VERIFIED 2026-07-04.
- [ ] Formatting applies from INITIAL submission (not deferred to
      acceptance, unlike the Nature-brand sibling profiles): double-line
      spacing, line AND page numbering, no page breaks, SI units, embedded
      special characters. VERIFIED 2026-07-04.
- [ ] Competing interests statement present for every author (or an
      explicit "no competing interests" statement), referring to authors by
      initials. Mandatory even when none exist. VERIFIED 2026-07-04.
- [ ] Authors' contributions statement present, referring to each author by
      initials. Mandatory. VERIFIED 2026-07-04.
- [ ] Cover letter present: explains journal fit, discloses any policy
      issues and competing interests, confirms all authors approved
      submission, confirms no duplicate/overlapping submission elsewhere
      (or discloses it), names the special issue/collection if applicable.
      VERIFIED 2026-07-04.
- [ ] Any LLM use in preparing the manuscript text is documented in the
      Methods section (BMC-wide AI policy, surfaced verbatim on this
      journal's own Perspective page). VERIFIED 2026-07-04.
- [ ] Manuscript submitted in an editable format (DOC/DOCX, RTF, or
      TeX/LaTeX with source files) — a PDF-only initial submission will
      require re-submission of an editable file at revision/acceptance.
      VERIFIED 2026-07-04.
SOFT:
- [ ] STREAMS guidelines checked, if applicable to the study design —
      flagged on the journal homepage as encouraged, not confirmed as a
      hard completion-required checklist (see SKILL.md TO VERIFY).
- [ ] Suggested/excluded reviewers drafted for the cover letter, with
      institutional email or ORCID/Scopus ID for suggested reviewers.
- [ ] APC waiver eligibility checked BEFORE submission if relevant —
      waiver requests made during review or after acceptance are not
      considered. VERIFIED 2026-07-04 (current APC £1890/$2590/€2190).
- [ ] CC BY vs. CC BY-NC-ND license preference decided ahead of acceptance.
- [ ] Preprint posting decision made (BMC explicitly does not treat preprint
      posting or conference presentation as prior publication).
