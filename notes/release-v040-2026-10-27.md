# v0.4.0 release preparation

The maintainer requested a GitHub v0.4.0 release on 2026-10-27. Scope is the
committed integration through `7075a17` and release preparation. The original
working tree's worksheet verification, five profiles, research/AIX and agent
files remain excluded. PyPI publication is not included.

## Changes since v0.3.1

- Declared input and profile/style/asset identities, stale-output detection and
  refusal to promote outputs when render inputs change mid-build.
- Document-scoped cross-references and captured Quarto diagnostics; final
  validation of declared transforms inside the render transaction.
- Context-aware abstract, display-item, highlights and word-count checks, with
  explicit estimation limits and shared profile validation.
- Optional explicit contextual audits, final DOCX inspection and converted
  previews; portable evidence tied to exact build identities.
- Separate locally attributed human decisions and agent proposals. Evidence
  does not establish scientific validity or author approval.
- Opt-in `si_references: true`: main links copy printed labels from the final
  SI captions, including generated/reordered floats. English numbered
  Figure/Table captions are supported; the result is plain text.

## Compatibility and validation

Plain `wongo check` still exits 0 when JSON `ok` is false; `--strict` exits 1.
Collab can still promote native unresolved-crossref warnings; submission cannot.
Explicit invalid SI links and mid-render input drift refuse both targets.
Wongo does not apply worksheet edits to QMD source or approve human gates.

The isolated integration candidate previously passed 889 tests (4 skipped),
full lint, package builds and offline profile verification. Release-revision
checks and remote CI will be recorded before publication.

On 2026-10-27 the maintainer explicitly waived private-reference parity for
v0.4.0 and deferred the native Windows/Korean-account/Word pilot to a future
release. Neither check was performed or passed. This is a release-specific
exception, not removal of the normal repository validation requirements.
Hosted CI and converted previews do not certify native Word behavior.
Do not upload artifacts from the original dirty working tree.
