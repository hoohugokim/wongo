# v0.3.1 release verification

The maintainer authorized the GitHub release on 2026-10-03 (Asia/Seoul), leaving
PyPI publication and native Windows/client validation for later work.

## Release contents

- Reference-inclusive submission word-count gate and per-type Nature counting.
- Affiliation labels beyond 26 and table geometry across document sections.
- Nested citation parsing, selective review and inline math/tab/break diffs.
- Native MCP tools, resources, prompts and client configuration, with the
  14 audit corrections in `dece132` and the tested SDK range `>=2.2.0,<3`.
- Source-aware review hints, retained proposal/decision history, and a measured
  synthetic workflow benchmark.
- Approved Wongo identity v1.0.0 with offline fonts, licensed runtime assets,
  reusable CSS/Quarto styling and updated repository documentation.
